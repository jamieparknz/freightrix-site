"dark" artwork with the navy background box and the 64px padding removed, so they sit
directly on the site's navy header and footer without showing a rectangle.

Colours on the site match the brand: navy #0A1630, lime #B9F23C.
The fonts are still Barlow. Archivo and Inter are the planned next step.

If the site is regenerated by the build pipeline, the page template must use these paths
too, or the old logos come back.

## Mobile layout (600px wide and under)

The build template must keep these too, or the next site build undoes them:

- Header: wordmark 14px tall, live pill shortened to "N closures" (`.lp-short`), and a
  menu button (`.menubtn`, controls `#sitenav`) that opens the nav as a full-width panel.
  The inline script after `</header>` toggles `.top.open` and closes on Escape or an outside tap.
- The live pill carries `aria-label="Road status: ..."` so screen readers get the full sentence.
- Traffic lights (`.legs`): 12px dots plus a coloured status chip (`.st`) that matches the dot,
  so status isn't shown by colour alone. Rows are at least 52px tall.
- Map (`.ausmap`): 84% width, capital labels 38 units, town labels hidden, thicker lines.
- Legend shows as a 2x2 grid.
- Tested with no sideways scroll on all 30 pages at 320, 360, 390, 430, 768, 1024 and 1280px.
