# FREIGHTRIX brand assets on the website

Source: logo system v1 (freightrix-logo.zip). The `*-web.svg` files are the official
"dark" artwork with the navy background box and the 64px padding removed, so they sit
directly on the site's navy header and footer without showing a rectangle.

| Where on the site | File | Size rule (CSS) |
|---|---|---|
| Header, desktop (over 1180px wide) | freightrix-horizontal-web.svg | 28px tall (245px wide) |
| Header, tablet (601 to 1180px) | freightrix-horizontal-web.svg | 22px tall (192px wide) |
| Header, phone (600px and under) | freightrix-wordmark-web.svg | 16px tall (192px wide), bigger letters than the full logo at that width |
| Footer | freightrix-horizontal-descriptor-web.svg | min(340px, 100%) wide |
| Browser tab | favicon.svg, with favicon-32.png as fallback | |
| iPhone home screen | apple-touch-icon.png (180) | |
| Android / installed app | icon-192.png, icon-512.png via /site.webmanifest | |
| Link previews (Slack, LinkedIn, iMessage, X) | og-image.png (1200x630) | |
| FIX sub-brand (not placed yet) | fix-web.svg | |

Colours on the site match the brand: navy #0A1630, lime #B9F23C.
The fonts are still Barlow. Archivo and Inter are the planned next step.

If the site is regenerated by the build pipeline, the page template must use these paths
too, or the old logos come back.
